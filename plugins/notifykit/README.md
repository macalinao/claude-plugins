# notifykit

macOS notifications for Claude Code using [notifykit](https://github.com/nichochar/notifykit).

Plays sounds when Claude needs your attention:

- **Glass** sound when Claude is idle and waiting for a prompt
- **Funk** sound when Claude needs permission to proceed

## Prerequisites

Install notifykit:

```bash
brew install nichochar/tap/notifykit
```

## Installation

```bash
claude plugin marketplace add macalinao/claude-plugins
claude plugin install notifykit@igm-claude-plugins
```
